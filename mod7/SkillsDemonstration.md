**What are 3 examples of problems that are in NP? Please be as descriptive as possible in describing these problems.**
1. Verifying a solved Sodoku puzzle, by going through the numbers and rows polynomially and checking if they abide by the rules of Sodoku.
2. Traveling Salesman Problem: Go through the cities given and figure out polynomially if each city appears in the route, returns to the starting city, and checking the total distance.
3. Subset Sum: Given a set of numbers, check if the numbers add up to a specified number.

**What is the difference between universality, computability, and intractability, in your own words.**
Universality is the idea that an algorithm doesn't have to be hard coded and can exist in memory alongside the data. This means that a computer can universally run any computable algorithm given to it.
Computability is whether or not something is physically able to be solved. An algorithm is computable if and only if it is computable by a turing machine or something similar, otherwise it is impossible.
Intractability is how computationally complex an algorithm is. Even if an algorithm can theoretically be solved, it may never be solved due to the fact it is so absurdly large and time consuming the algorithm is.
